# productivity_app

A personal goal planner that runs in your browser. It keeps track of long-term
and short-term goals, breaks them into tasks, and schedules those tasks into the
free time you have each week (with Google Calendar sync planned).

## Running it

You need [Node.js](https://nodejs.org/) 20 or newer installed.

```bash
npm install     # first time only
npm run dev     # starts the app
```

Then open the address it prints (usually http://localhost:5173).

Your data is saved in your browser on this computer. Use **Settings → Export
backup** to save a copy to a file.

## Using it

- **Today** lists focus tasks for each active goal: about 2 hours a day by
  default (change it per goal on the goal's page). Tasks come in order of due
  date. Ticked-off tasks stay on the list for the rest of the day.
- **Pause / Resume** a goal from its page. Paused goals drop off Today. When
  you resume, unfinished due dates move later by however long it was paused.
- **Goals → + New goal**: write one short-term goal per line, with its tasks
  indented or bulleted underneath. Add `(30m)` or `(2h)` to a task to set its
  time (default 1 hour). Due dates are spread up to the finish date if you set one.

## Goals added from chat

Claude keeps the goals you describe in chat in `scripts/build_goals.py`, which
writes `src/data/goals.json`. After you pull (`git pull`), new goals show up the
next time you open the app. Your ticked-off tasks are kept, and goals you delete
in the app stay deleted.

## Project layout

- `src/data/types.ts` – the data model (goals, tasks, availability)
- `src/data/storage.ts` – saving to the browser, export/import
- `src/data/goals.json` – goals added from chat (generated by `scripts/build_goals.py`)
- `src/data/focus.ts` – how Today picks each day's focus tasks
- `src/breakdown/templates.ts` – turns a goal outline into short-term goals and tasks
- `src/components/` – the app's screens
- `npm test` runs the unit tests
